# BitOasis

> BitOasis is a MENA-region cryptocurrency exchange (Dubai VARA-licensed VASP) for buying, selling, and trading digital assets against the UAE Dirham (AED) and other fiat. Its v1 Exchange REST API and an official MCP server provide public market data and authenticated account, order, deposit, and withdrawal operations.

## API
- [BitOasis Exchange API (OpenAPI)](https://raw.githubusercontent.com/api-evangelist/bitoasis/refs/heads/main/openapi/bitoasis-exchange-openapi.yml): v1 REST API at https://api.bitoasis.net/v1 — markets, tickers, order books, trades, balances, banks, orders, and crypto/fiat deposits & withdrawals. Bearer API-token auth.

## MCP
- [BitOasis MCP server](https://github.com/bit-oasis/bitoasis-mcp): official first-party MCP server (PyPI `bitoasis-mcp`, `uvx bitoasis-mcp`); remote SSE at https://mcp.bitoasis.net/sse. 23 tools over the v1 API.
